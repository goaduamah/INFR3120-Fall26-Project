# Campus IT Help Desk

Campus IT Help Desk is a web application that allows students to report technical problems they experience on campus.
Students can submit support tickets for issues involving Wi-Fi, hardware, software, and student accounts. The application also includes a dashboard where submitted tickets can be viewed along with their current status.
This project was developed for INFR3120 Fall 2026 as part of Project.


## Features

- Homepage with an original team logo.
- Support ticket submission form.
- Form validation to prevent incomplete submissions.
- Ticket dashboard for viewing submitted tickets.
- Dashboard summary showing total, open, in-progress and resolved tickets.
- Ticket details including student name, email, category, description, and status.
- Basic navigation.
