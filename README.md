# Campus IT Help Desk

Campus IT Help Desk is a website we created to make it easier for students to report technical problems on campus.
Students can use the website to submit support tickets for problems with Wi-Fi, hardware, software, or their accounts. They can also view submitted tickets on the dashboard and check their current status.
This project was developed for INFR3120 Fall 2026 as part of Project Part 1.


## What You Can Do on the Website

- Visit the homepage to learn about the Campus IT Help Desk.
- Create a support ticket by entering your details and describing the problem.
- Choose a category for the issue, such as Wi-Fi, hardware, or software.
- View submitted tickets on the dashboard.
- Check the status of tickets, including Open, In Progress, and Resolved.
- See a summary of the total number of tickets submitted.


## How We Built the Website

- Node.js to run the application.
- Express.js to handle the website routes and requests.
- EJS to display the different pages.
- HTML and CSS to build and style the pages.
- Bootstrap to help with the page layout and buttons.
- JavaScript to handle form submissions and ticket information.
- Git and GitHub to manage our code and work together.


## How to Run the Website

1. Download or clone the project from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project folder.
4. Run `npm install` to install the required packages.
5. Run `npm start` to start the website.
6. Open `http://localhost:3000` in your browser.



## Current Version

This is the first release of the Campus IT Help Desk. Ticket information is currently stored in memory while the application is running. This means submitted tickets will reset when the server restarts.
The project can be improved in future releases by adding a database to keep ticket information permanently.
